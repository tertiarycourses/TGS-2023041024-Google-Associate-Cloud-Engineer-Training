# TGS-2023041024 - Google Associate Cloud Engineer Training

> Course: Google Associate Cloud Engineer Training  
> Course Code: TGS-2023041024  
> Register here: https://www.tertiarycourses.com.sg/wsq-google-associate-cloud-engineer-training.html

Hands-on Google Associate Cloud Engineer labs for learners preparing to deploy, secure, monitor, and maintain Google Cloud solutions. The labs cover projects, billing, IAM, Cloud Shell, `gcloud`, VPC networking, firewall rules, DNS, load balancing, Compute Engine, managed instance groups, Cloud Storage, Cloud SQL, GKE, Cloud Run, monitoring, logging, troubleshooting, security, and exam review.

## How to Use These Labs

1. Read the learner guide before starting the first lab.
2. Complete the labs in order because later exercises reuse concepts from earlier labs.
3. Use a Google Cloud training account, sandbox, or free trial account with billing controls enabled.
4. Clean up resources at the end of each lab to avoid unexpected charges.
5. Review the reflection questions and exam checkpoints after each lab.
